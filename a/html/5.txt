### 页面所有 a 标签统一去除（style 标签写在 html 内）

```
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<style>
a {
  text-decoration: none;
}
</style>
</head>
<body>
<a href="#">链接1</a>
<a href="#">链接2</a>
</body>
</html>
```


### 单个 a 标签（行内样式，直接写标签内）

```
<a href="https://xxx.com" style="text-decoration: none;">链接文字</a>
```
