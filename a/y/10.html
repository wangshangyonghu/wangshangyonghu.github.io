使用方法

  1. 点击上方上传区域，或把图片拖进来（可多选，支持 JPG / PNG / WebP / GIF / BMP）。
  2. 填写压缩设置（见下表），点「开始压缩」。
  3. 结果列表显示每张压缩前后大小与节省比例；点击结果图片弹出「压缩后 vs 原图」对比查看效果。
  4. 点单张「下载」，或点「全部下载」打包为一个 ZIP（纯浏览器打包，无需服务器）。

设置项说明

设置项说明
目标大小每张压到该大小以内。填 3M、500K、1.5M 均可；留空则按固定质量压缩
质量JPG / WebP 压缩质量（1-100），默认 80。有目标大小时程序自动迭代质量
最大宽度超过该像素宽度时等比缩小，留空不缩放
输出格式自动（尽量保持原格式）/ JPG / PNG / WebP
允许转格式PNG 或大图压不到目标时，自动尝试转 WebP / JPG（更小），勾选后生效

注意事项

  • GIF 动图：默认保持动画原样；勾选「允许转格式」后才会转成静态图进一步压缩。
  • EXIF 信息：压缩后拍摄参数等 EXIF 会被移除（这也是体积变小的原因之一）。
  • WebP 兼容：Chrome / Edge / Firefox / Safari 14+ 均支持；极老浏览器可能打不开 WebP。
  • 隐私：图片全程在浏览器本地处理，不上传任何服务器，断网也能用。
  • 大图：单张超过 60M 或超过 4000 万像素会被拒绝，属正常保护。
  • 结果保存：压缩结果在浏览器内存中，刷新或关闭页面即消失，请及时下载到本地。
  • 原图安全：原图不会被修改或删除，压缩结果另存为新文件（原文件名 + _ys）。

常见问题

  • 压缩后比原图还大？ 小图或已高度压缩的图不会再变大，程序会自动保留原图。
  • PNG 压不到目标大小？ PNG 是无损格式，属正常现象；勾选「允许转格式」即可解决。
  • 全部下载没反应？ 文件较大时打包需要几秒，请稍候；也可改用逐张下载。
