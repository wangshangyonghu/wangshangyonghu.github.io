使用说明（点击展开）

使用方法

  1. 点击上方上传区域，或把图片拖进来。
  2. 勾选需要的图标尺寸（16 / 32 / 48 / 64 / 128 / 256 等，可多选）。
  3. 选择是否需要「裁剪为正方形」与「保留透明背景」。
  4. 点「重新生成 ICO」，预览各尺寸效果，再点「下载 .ico」保存。

设置项说明

设置项说明
包含尺寸最终 .ico 文件里打包的尺寸，Windows 会自动挑选合适大小显示
裁剪为正方形非正方形图会居中放入正方形画布，多余部分用背景色填充
保留透明背景源图有透明区域时保留；关闭时背景填白

注意事项

  • 推荐 256px 或更高分辨率源图，小图放大后会模糊。
  • 透明背景：PNG 透明区会被保留；JPG 无透明，自动填背景色。
  • 兼容性：生成的 ICO 使用 PNG 编码，Windows Vista 及以后的系统均支持。
  • 隐私：图片全程在浏览器本地处理，不上传任何服务器，断网也能用。
  • 结果保存：生成结果在浏览器内存中，刷新或关闭页面即消失，请及时下载。
