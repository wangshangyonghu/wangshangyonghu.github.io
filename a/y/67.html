常用书签脚本大全

不用装任何插件，在浏览器收藏夹存一条 javascript: 开头的链接，点一下就在当前网页上执行。下面按用途分好类，需要哪个复制哪个。

一、这是什么

这种写法叫 书签小脚本（Bookmarklet）：把一段 JavaScript 代码存成书签，点书签时浏览器会在当前页面执行这段代码。它不依赖网站本身，所以任何网页都能用。

免安装、免插件、不占内存；换浏览器或换电脑，只需重新存一遍书签。
误操作破坏了页面，按 F5 刷新即可恢复。

二、添加方法（Chrome / Edge 通用）

  1. 在收藏栏空白处右键 → 选择【添加网页…】/【添加书签】。
  2. 名称填：回到顶部（写自己看得懂的名字）。
  3. 网址 / URL 一栏，粘贴下面完整的一行代码（以 javascript: 开头，一个字符都不能少）。
  4. 点【保存】，收藏栏就多了一条，点它即生效。

快捷键 Ctrl + Shift + B 显示/隐藏收藏栏。手机浏览器（夸克、UC、Chrome 移动版）在"书签管理"里也能新建网址书签，写法完全一样。

三、滚动类

1. 平滑回到顶部（推荐，有滚动动画） 
javascript:window.scrollTo({top:0,behavior:'smooth'});
2. 瞬间跳回顶部（无动画，一秒到位） 
javascript:window.scrollTo(0,0);
3. 平滑滚到页面最底部 
javascript:window.scrollTo({top:document.body.scrollHeight,behavior:'smooth'});
4. 上下跳 90% 屏（长文快速浏览） 
javascript:window.scrollBy({top:window.innerHeight*0.9,behavior:'smooth'});

七、注意事项（重要）

1. 前缀不能丢：必须以 javascript: 开头，整行一次性粘贴，不要带换行和多余空格，不要被浏览器自动补成 https://。

2. 部分网站会失效：启用 CSP 安全策略的网站会禁止执行书签脚本，点了没反应属正常现象，不是代码错。

3. 只能在网页里点：空白新标签页、浏览器设置页等非网页界面点了无效。

4. 别点陌生人的脚本：别人发来的 javascript: 链接可能是恶意代码，只存你自己确认过的。

5. 破坏页面就刷新：执行后排版乱、文字没了，按 F5 刷新即恢复原样，不会改坏网站。

手机浏览器若长按书签只出现"打开/编辑"，请先存好书签后再从收藏夹点选；iOS Safari 需在"书签"里新建，粘贴时注意不要粘贴成两个书签。

八、常见问题

  • 点了完全没反应？先看网址栏里是不是少了 javascript:；再确认这个网站是否限制了脚本。
  • 浏览器把代码变成了搜索？说明前缀被吞了，删掉书签重新整行粘贴一次。
  • 想放到手机用？手机 Chrome / 夸克添加书签时，把整行代码粘贴到"网址"栏即可，用法和电脑一样。
  • 想恢复原样？除了刷新，深色、黑白、白底这三条都是"再点一次"切换回去。
